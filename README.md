## Публикуване

1. Качи файловете в корена на GitHub репозитория.
2. Отвори **Settings → Pages**.
3. Избери **Deploy from a branch**, текущия клон и `/ (root)`, после натисни **Save**.
4. След публикуването GitHub ще покаже адреса на сайта в раздела Pages.

Това е статичен сайт и не се нуждае от сървър или база данни.

## Режим за представяне

Страницата се превърта естествено. Бутоните на екрана и менюто плавно преместват към избран раздел; когато се появи нов раздел, съдържанието се показва с морфиращ преход. Ако разделът е по-висок от екрана, може да се превърти свободно до края.
